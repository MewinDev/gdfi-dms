## Rule names

The automatic rules are never shown by number. Each has a stable key (code, stored records, audit and tests), a short title and one plain sentence with the loan's values; all wording is in `lib/rules/names.ts` and nothing else writes it. On screen a decision reads "title · reason"; the classification is one complete sentence with no title. The amounts come from the mortgage thresholds (`MORTGAGE_THRESHOLDS`, fixed in code: ₱500,000 for New, ₱1,000,000 for Renewal). New loan files store the key (`Loan.ruleFired`, for example `MORTGAGE_THRESHOLD:New:MET`); older ones stored the old sentence, which is read and shown in the new words, and old audit rows are not edited.
